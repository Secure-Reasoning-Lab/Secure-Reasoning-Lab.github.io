# Secure Reasoning Lab

Website for the Secure Reasoning Lab at New York University Abu Dhabi.

- Live site: <https://secure-reasoning-lab.github.io/>
- Organization: <https://github.com/Secure-Reasoning-Lab>
- PI: [Jiahao Yu](https://sherdencooper.github.io/)

This site is built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and hosted on GitHub Pages.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://localhost:4000`.

## Editing

| What | Where |
| --- | --- |
| Lab intro | `_pages/about.md` |
| People | `_pages/people.md` |
| Research themes | `_pages/research.md` |
| Recruiting | `_pages/join.md` |
| Papers | `_publications/` |
| News | `_posts/` |
| Site title, sidebar, URL | `_config.yml` |
| Top menu | `_data/navigation.yml` |
| Logos | `assets/` and `images/` |
